# Custom Notification Sounds

Place your custom notification sound files in this directory.

## Supported Formats:
- **Android**: mp3, wav, ogg
- **iOS**: aiff, wav, caf

## File Naming:
- Use lowercase letters
- Avoid spaces (use underscores instead)
- Example: `notification_sound.mp3`

## Requirements:
- Android: Sound file should be placed here and referenced as `sound/notification_sound.mp3`
- iOS: Sound file should be placed here and referenced as `notification_sound.mp3` (without the sound/ prefix)

## Default Sound File:
Add a file named `notification_sound.mp3` or `notification_sound.wav` to this directory to use as your custom notification sound.
